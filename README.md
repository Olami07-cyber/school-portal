# School Portal

## Project Structure

- `index.html` - application entry point
- `pages/` - portal screens and authentication pages
- `assets/styles/` - shared and page-specific CSS
- `assets/scripts/` - page-specific JavaScript
- `assets/images/` - images used by the portal
- `assets/study-materials/` - downloadable course files

## Main Pages

- `pages/login.html`
- `pages/dashboard.html`
- `pages/academics.html`
- `pages/exam-results.html`
- `pages/study-materials.html`
- `pages/profile.html`
- `pages/settings.html`

Open `index.html` to start the portal.
